Official Octo Language Documentation

Follow these steps to set up and write scripts using the octopus-themed .oct development environment.

1. Cross-Platform Local Installation

Download the repository .zip package, extract the assets, and run the matching launcher script for your operating system terminal prompt:

# For Windows Command Prompt Users
$ octo.bat your_script.oct

# For Mac / Linux Terminal Shell Users
$ ./octo.bash your_script.oct

2. Built-in Core Commands Table

Syntax Command Functional Purpose Expected Output / Action
var [name] Memory Reference Allocation Initializes a fresh, empty variable state tracked as NIL.
Squirt("text") Standard Terminal Console Output Prints plain-text string values directly down into the debugging screen.
Splash("text") Persistent Graphical Layer Text Projects text overlays directly onto the primary runtime display layer.
Sklink$ Physical File Removal Operation Deletes a file, returning a true or false boolean validation status.
Demolish~~ Logical Branching Control Block Evaluates conditional system rules and statements before processing lines.
DrawOn(Axis, Y, X, Z) 3D Spatial Vector Rendering Canvas Plots canvas layout graphics. Requires AxisYXZ and draw.py imported to run.
